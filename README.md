# 观澜中国史

一个纯静态的历史学习网站原型。打开 index.html 即可运行；不收集用户数据，也不依赖服务端。

## 内容说明

- 站点中的历史文本是界面样例，不应替代正式的专家审校稿。
- “史实、传说、文学演绎”的区分是正式内容工作流的一部分。
- 正式上线前，每一篇内容均应补齐版本化参考文献、审稿记录与图片授权信息。
